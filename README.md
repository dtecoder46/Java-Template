# Java-Template
Use this repo to jumpstart an CLI-based Java project!

# Features
1. Two Java resources are provided in this README to help you through your Java journey!
2. Espresso, a simpler version of Java, is bundled in this template to main writing Java less painful! It includes:
    1. A Java-like syntax without the semicolons
    2. Classes for printing and writing to files bundled into the repo to abstract away their respective tedious syntax

# How to Run
1. Install Java (https://www.java.com/en/download/)
2. See the Espresso docs for further instructions (https://github.com/dtecoder46/Espresso)
